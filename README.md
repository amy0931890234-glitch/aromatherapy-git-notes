# 法系醫學芳療與臨床植物醫學專題研究庫 (French Medical Aromatherapy & Clinical Phytotherapy Research Monograph Repository)

本儲存庫收錄**法系醫學芳療（L'aromathérapie médicale）**與**臨床植物醫學（Clinical Phytotherapy）**在生理學、病理藥理學及受體生物學領域的深度專題文獻與臨床對照矩陣。

---

## 📚 專題研究目錄 (Table of Contents)

### 1. 🫁 [呼吸道免疫與肝臟代謝協同機制專題](./french_medical_aromatherapy_and_notes.md)
* **主軸**：排泄器官負荷理論（Émonctoire）、第二屏障轉移機制、呼吸道病理進程與分子藥理對接、肝-肺共治（Foie-Poumon Synergy）。
* **核心分子**：側柏醇（Thujanol）、馬鞭草酮（Verbenone）、胡蘿蔔醇（Carotol）、1,8-桉油醇（1,8-Cineole）、格陵蘭喇叭茶（Germacrone/Sabinene）。

### 2. ⚡ [新陳代謝、細胞能量學（AMPK/PPAR）與內分泌網絡調控專題](./metabolic_aromatherapy_and_clinical_phytotherapy.md)
* **主軸**：代謝症候群、胰島素抗性、白色脂肪棕色化（UCP-1）、非酒精性脂肪肝（NAFLD）、HPA 軸皮質醇型內臟脂肪堆積與尿酸代謝引流。
* **核心分子**：諾卡酮（Nootkatone）、肉桂醛（Cinnamaldehyde）、黑種草酮（Thymoquinone）、右旋單萜烯（d-Limonene）、芹菜酞（Sedanolide）。
